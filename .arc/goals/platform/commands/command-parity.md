# Preserve workflow identity across operator interfaces

Provide equivalent authorized submission, reading, answering and cancellation through browser, REST, MCP and platform CLI using the shared application lifecycle. Keep operator MCP distinct from activity-scoped agent tools.

Retain durable receipts linked to the execution and exact open question. Reconnect, project switching and adapter restart recover the receipt. Closing a question preserves its draft while the gate remains open; successful answering removes the action and resumes the original request.

For bare Run, retain the captured inventory and checkpoint the exact aggregate result before closing its round. Recovery returns a completed result with its original identity or resumes unfinished work without duplicating accepted outcomes.

## Success measures

- Equivalent interfaces preserve authority, outcomes and exact gate identity.
- Adapter disconnect leaves host execution active.
- Answer and cancellation retries reconcile retained state without duplicate effects.
- Recovery between round completion and receipt completion returns the original result.
