# Provide the approved responsive application frame

Provide the mobile-first browser frame against the approved visual and interaction reference. Preserve Plan, Architect, Run and Release navigation order, pinned workspace navigation and destination-heading focus.

Support named site schemes and persistent browser preferences. Provide the docked command panel with reviewed desktop and mobile states, control ordering and centered metrics dialog. Show unavailable commands and missing metrics explicitly; failed submissions preserve the operator's instruction.

Keep frame acceptance separate from subsequent feature displays. Local shell and controlled bindings do not authorize live commands; real-project activation retains the existing qualification boundary.

## Success measures

- Real-browser acceptance covers desktop and mobile navigation, focus, themes and dock behavior against the approved reference.
- Theme preferences survive refresh.
- Controlled bindings exercise active, waiting and failed submissions without losing instructions.
- Shell-only controls cannot initiate unauthorized host operations.
