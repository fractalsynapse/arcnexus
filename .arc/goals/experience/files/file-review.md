# Provide trustworthy reusable file review and editing

Let operators discover files, inspect full identity and captured revision, and review complete content and diffs. Provide rendered Markdown and raw editing views that preserve drafts and access to syntax unsupported by rich editing. Architecture forms and raw YAML share the owning schema as their validation source.

Keep editing, validation and approval behind the applicable public service boundary. Distinguish local preview drafts from accepted source. Switching or expanding views preserves drafts and useful review state.

Approve the shared file experience before reuse across workspaces. Converge accepted live and fixture views on shared presentation while preserving legacy references until their migration is accepted.

## Success measures

- File identity, revision, content and diff agree across views.
- Markdown and YAML drafts survive switching and expansion.
- Invalid schema input and unsupported rich syntax remain inspectable without data loss.
- Shared presentation changes affect live and fixture views from one maintained source.
