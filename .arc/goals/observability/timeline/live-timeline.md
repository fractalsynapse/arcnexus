# Expose a complete live execution timeline

Capture and stream provider-exposed messages, updates, tool calls, complete results, diagnostics, usage and outcomes through the existing journal and evidence path. Retain exact invocation context before activation, unknown events and malformed output. Keep credential values outside records.

Correlate observations with execution, phase, activity, model, runtime and effects. Associate updates with their original item and avoid double-counting an operation observed by both host and harness.

Human output and structured streams expose the same ordered observations before completion. Preserve the acknowledged prefix across cancellation, stream boundaries and restart. Complete artifacts remain readable through existing references.

## Success measures

- A real provider workflow emits useful observations before completion.
- Tool results, refusals, usage and terminal outcomes remain attributable and readable.
- UTF-8 boundaries, unknown events, stderr and interruption preserve observation history.
- Timeline and artifact reads grant no additional authority.
