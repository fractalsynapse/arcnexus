Production path. The public HostTask.check(id, signal, scope) in packages/execution/src/index.ts delegates to runCheck in src/run-check.ts. runCheck validates the captured command and applicability, then constructs CheckDependencies when an applicable candidate has package.json. CheckDependencies.prepare runs before observation reuse or the requested check. A failed preparation becomes a CheckResult with the requested operation ID, prerequisite: dependencies, the original numeric status and original log. This explicitly prevents the prerequisite from satisfying expected behavioral failure. The low-level check() default referring to the source checkout's node_modules is not the production repair seam: runCheck supplies the candidate's managed installation.

Preparation implementation. packages/execution/src/dependencies.ts computes its key from canonical remote, candidate package.json, package-lock.json, npm-shrinkwrap.json and .npmrc, runtime/tool identities, and conservative local inputs where necessary. Installation lives at task.config.storage/dependencies/<key>/node_modules. Reuse requires prepared.json with matching input and successful status, an existing retained log and installed .package-lock.json. Failed or interrupted preparation has no successful receipt and its partial installation is discarded before retry. install() calls checkMounts(worktree, common, directory, true), then conditionally overlays join(homedir(), '.npm', '_cacache') at /tmp/npm-cache/_cacache. This source is the execution host process's home, not the sandbox HOME, Codex credential directory, arbitrary npm cache configuration, or an installation in the original checkout.

Confinement and configuration. packages/execution/src/check-sandbox.ts uses bubblewrap --unshare-all, --clearenv, a temporary /tmp, a disposable worktree overlay and a writable mount only for preparation's managed node_modules. It sets HOME=/tmp, PATH=/usr/local/bin:/usr/bin:/bin, GIT_CONFIG_NOSYSTEM=1 and GIT_OPTIONAL_LOCKS=0. The npm cache overlay is temporary; it does not populate the original host cache. packages/execution/src/host-config.ts exposes capture, common, executable, base, fresh, storage, optional runtime and GitHub credentials, with no npm-cache or preparation-command override. Its binding resolves tools.codex, not dependency setup.
