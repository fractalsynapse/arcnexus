# Provide the approved responsive application frame

Provide the mobile-first browser frame using the approved visual and interaction reference. Keep Plan, Architect, Run and Release navigation in its reviewed order, with pinned workspace navigation and destination-heading focus.

Support named site schemes and persistent browser preferences. Provide the docked command panel with appropriate desktop and mobile states, reviewed control ordering and a centered metrics dialog. Show unavailable commands and missing metrics explicitly. Failed submissions preserve the operator's instruction.

Maintain separate acceptance slices for the frame and subsequent feature displays. The local shell and controlled bindings do not authorize live commands; real-project activation follows the existing qualification boundary.

## Observable success

- Real-browser acceptance covers desktop and mobile navigation, focus, themes and dock behavior against the approved reference.
- Theme preferences survive refresh.
- Controlled bindings exercise active, waiting and failed submission states.
- Shell-only controls cannot initiate unauthorized host operations.
