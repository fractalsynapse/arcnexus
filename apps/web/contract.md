# Local web app

Stage · **Proposed**.

The local web app composes workspace registrations using the [UI plugin](../../packages/ui/contract.md).
Its first delivery serves built static assets on loopback. The production
binding reports commands and round measurements as unavailable. Browser
acceptance supplies a controlled binding to the same composition.

The first delivery covers the frame described in the
[web frame migration plan](../../docs/plans/web-frame-migration.md).
