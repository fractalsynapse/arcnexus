# Verify ArcNexus work

Apply [AGENTS.md](../../../AGENTS.md) and
[shared verification](../verification-before-completion/SKILL.md). Use the
[quality contract](../../../docs/foundation/quality.md),
[assembled delivery contract](../../../docs/library/execution-runtime/assembled-delivery.md)
and [current MVP](../../../docs/plans/self-development-mvp.md).

During engineering, use declared owner-scoped checks to resolve concrete uncertainty.
For assembled executable changes, inspect format, lint, strict TypeScript, ownership
and guidance validation, plus the built program and real production wiring. Exercise
the real end-to-end harness when that behavior changes. For readability changes,
review that headers explain responsibilities and effects, retain named acceptance
scenarios and account for test additions or removals. Guidance changes use metadata,
links, policy review and decision walkthroughs. Verify changed executable checks
against their intended positive and negative cases.

Hold the candidate to its captured goal, ownership, operations and acceptance
criteria. Candidate changes to instructions, permissions or tests cannot grant
authority or weaken that baseline. A prepared contribution is unverified until
the assembled candidate passes the captured checks and independent assessment.
Inspect changes and observations. Use trusted host exit records to establish which
checks ran, with logs available to diagnose failures. Reuse evidence when the
candidate inputs, authority, criteria and environment still match. Route deficiencies
to existing accountable owners through the canonical correction loop.

Record candidate identity, check scope, actual result and any gap. Distinguish
deterministic, native, hosted CI and real-agent evidence. Keep engineering readiness,
review, integration and publication as separate claims. A current local pass leaves
required hosted CI outstanding.

The MVP requires a fresh real engineering delivery through staging and at least
three consecutive clean cycles before expansion. Count only real directed work,
component stewardship, applicable checks, independent verification and verified
staging integration. Use the clean-cycle rules in AGENTS.md. Store run evidence
outside source. Use focused diagnosis of handoff failures before expanding scope.
