# Qualification and historical campaigns

Use real-agent `task run "<prompt>" --simulate` and `workday start --simulate`
for current lifecycle qualification. The actual director selects eligible project
stewards; scripted cases and prescribed teams do not satisfy real-agent gates.
Retain verified diffs, independent assessments and complete publication evidence.

Run deterministic campaign assertions through `test inspect/run --component
experiments`. The executor is test support and is absent from the production build.
`experiment run` and legacy single-steward execution are retired. Historical
manifest inspection and existing report vocabulary remain readable; they do not
authorize another execution path. See [campaign evidence](experiments.md),
[prior qualification](../../acceptance/pre-phase-two.md) and
[operations qualification](../../acceptance/steward-operations.md).
