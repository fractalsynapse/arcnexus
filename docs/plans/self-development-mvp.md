# First delivery and qualification

Build the host CLI in observable increments. Use the applicable [locked scenarios](../interface/README.md)
for each slice. Bootstrap through the normal repository workflow until ArcNexus can
carry a real change. Label earlier integration evidence by the slice it proves.

1. Exercise `inspect` from the built CLI. Show the model-facing request produced by
   the same builder then used at the Codex boundary. Check parity for the same inputs
   and identify runtime-only placeholders.
2. Deliver one fresh goal with one steward through staging. Supply an objective,
   inspect the actual checked edit and diff, follow progress, and observe the host
   checks, independent verdict, PR and provider merge identity.
3. Deliver a goal needing a second owner. Have the director sequence the supplier
   before dependent work in the same task worktree. Verify each owner's attribution
   in one candidate and staged delivery. Exercise an escalation requiring a decision.
4. Observe an out-of-owner write refusal and cancellation with retained evidence.
   Exercise host confinement and ensure an interrupted upstream effect is observed
   before any retry.

Qualify a real ArcNexus improvement through the same loop on one machine without
operator hand-edits. Record three consecutive clean real cycles before expanding
the surface. Unexpected execution failures, manual state repair or a bypassed
check break the sequence. Deliberate negative tests and an observed expected red
are normal evidence. A change to the execution path restarts qualification.

Run deterministically where a decision can be tested without inference. Use the
production composition and real model for live qualification. Record evidence
identity, scope, wall time, model turns, changed lines, and blocked or failed
outcomes with causes. Record unavailable measures explicitly. Report local checks,
host enforcement, hosted CI and live acceptance separately.

The first build defers the broader CLI surface, workdays, the simulation provider,
production release, external plugin management, and service gateways. The
[CLI plugin](../../packages/cli/contract.md) defines the first operator commands.
